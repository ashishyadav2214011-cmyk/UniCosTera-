# UniCosTera Home Page Specification

Hero: a living cosmic visual rather than a static dashboard.

Visual progression:
Early Universe → Particles → Atoms → Stars → Galaxies → Planets → Life → Intelligence

Primary:
- Start Universe
- Explore Cosmos
- New Experiment

UniTera AI:
Understands the user's requested WHAT, routes context to Unico. Simulation, and explains results, assumptions, uncertainty and consequences.

Simulation discovery:
Universe, Stars, Planets, Life, Intelligence, Black Holes.

Experiment:
REAL / REFERENCE → PROTECTED STATE → single independent EXPERIMENT COPY → user changes → Unico. Simulation → consequences/comparison.

Timeline:
Rewind, Play, Pause, Fast Forward, Historical Observation, Branching, Event History, Snapshots.

Life & Habitability:
Chemistry → Life → Evolution → Intelligence.

Observer:
Zoom, Measure, Inspect, Scientific Data, Historical Observation.

Global controls:
Simulation Controls, Privacy, Scientific Data, Saves, Performance, Online/Offline, About.

Android:
Navigation remains usable on Android. Adaptive performance may change visual quality, but must not silently corrupt scientific state or arbitrarily cut off simulation.
