# UniCosTera — Phase 2 Execution Pipeline

## Standard execution

1. User submits request.
2. UniTera AI interprets the request.
3. AI identifies required parameters and constraints.
4. Complexity is assessed.
5. A manageable task may execute in UniTera AI.
6. A complex task is routed to Unico. Simulation.
7. Unico. Simulation applies scientific rules/models.
8. User-controlled parameters are applied as causes.
9. Scientific consequences are calculated.
10. Result/state is returned.
11. UniTera AI explains the result.
12. Scientific labels and fidelity status are displayed.

## No silent fabrication

If requested fidelity cannot be maintained on the current Android device, the system must adapt transparently and label the resulting fidelity/approximation.
