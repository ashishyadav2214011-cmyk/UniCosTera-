# Android Ultra-Hard Simulation Rule

Ultra-hard simulation remains a core functional target on Android.

The system may adapt computation using:

- CPU parallelism
- GPU acceleration
- adaptive timestep
- adaptive resolution
- adaptive representation
- statistical/aggregated representation where scientifically justified
- level of detail
- memory management
- progressive execution
- checkpointing
- pause/resume

## Principle

Adaptive computation must remain scientifically honest.

Reduced fidelity, approximation or uncertainty must be explicitly labelled.

The system must never claim exact high-fidelity computation when it actually used an approximation.
